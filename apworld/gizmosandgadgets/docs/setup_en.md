# Gizmos and Gadgets setup

The full guide is on the project page:
[docs/setup.md](https://github.com/FlapjackRetro/gizmos-and-gadgets-ap/blob/main/docs/setup.md).

In short:

1. Build the native recompilation (`gizmos.exe`, from
   [gizmos-and-gadgets-recomp](https://github.com/FlapjackRetro/gizmos-and-gadgets-recomp)) from your own copy of
   the game (DOS v1.0), in a game folder used for this seed only.
2. Put `ap_mod.dll` (from the project's Releases page) into `<game folder>\mods\`.
3. Install `gizmosandgadgets.apworld`, start the **Gizmos and Gadgets Client** from the Archipelago Launcher, set
   the game folder once with `/gamedir <path>`, and connect.
4. Start `gizmos.exe` and create a new player for this seed.

Received parts wait in the Pieces box in the assembly room; click it to put them on the conveyor. Client
commands: `/game` (game status), `/levels` (open levels).
